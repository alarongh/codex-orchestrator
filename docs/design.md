## Почему один вход

Пользователю достаточно знать одно имя. При запуске Codex получает короткие метаданные скилла, при выборе читает основной файл, затем открывает только нужные инструкции. Подробности хранятся в справочных файлах скилла и открываются по маршрутам основного файла. Опциональный мост через `AGENTS.md` явно запрашивает этот режим; скилл не запускает сам себя из дочерней роли.

Дополнительный агент получает свой контекст и тратит время на запуск. На маленькой обратимой задаче выгоднее прямая работа с точечной проверкой. На большой задаче лёгкая модель полезна для понятного ограниченного поручения, а независимую работу можно начать параллельно. Профильный навык открывается, только когда помогает сделать или проверить конкретную часть результата. Экономию оцениваем по времени до проверенного итога, полному расходу токенов и качеству на одинаковых задачах.

Три уровня контроля: исполнитель сам проверяет свою работу, независимый критик ищет расхождения, ведущий принимает результат. Проверка применяется к реальной версии файла, коммита или интерфейса, а состояние публикации подтверждается отдельно.
